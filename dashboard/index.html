      How this comparison works
      • Two modes. Market price comparison puts housing and SPY price levels on one scale (Index = value ÷ 2015 value × 100). It is a price comparison, not an investment return comparison. Investment returns shows what an investor in SPY actually earned, with dividends reinvested.
      • Housing prices. Avg / Median sale price come from MLSListings closed sales for your filters. They move with the mix of homes sold (size, location, type), so they are not the same as appreciation of a given home. FHFA HPI is a repeat-sales index (the same houses sold or appraised more than once), so it measures appreciation more directly — but it is county-level, annual, and single-family only.
      • SPY. SPY price uses closing prices without dividends. Total return uses dividend-adjusted closes, so dividends are assumed reinvested. In price mode yearly values are averages of monthly closes (to match yearly average home prices); in investment mode returns run month-end to month-end (Dec 31 to Dec 31 for a calendar year).
      • Not included. Rental income, mortgage financing and leverage, property tax, insurance, maintenance, and transaction costs. That's why housing has no investment return here.
      • Partial years. Only complete months are used. A year-to-date value is compared with the same months of the previous year (e.g. Jan–Oct vs. Jan–Oct) and its index is provisional. Growth rates (CAGR) use full years only.
      • Sources & updates. MLSListings RESO Web API; SPY monthly closes from Yahoo Finance; FHFA All-Transactions HPI via FRED. All refreshed when you run npm run fetch:history.
